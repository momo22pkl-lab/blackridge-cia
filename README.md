# BLACK RIDGE CITY CIA SYSTEM

## تشغيل محلي

يتطلب Node.js 18 أو أحدث.

```bash
npm ci
npm start
```

قبل تشغيل النظام، عرّف متغيرات البيئة التالية. لا تضعها داخل Git أو داخل الواجهة:

- CIA_CHIEF_REGISTRATION_CODE: كود تأسيس القيادة لمرة واحدة.
- CIA_CHIEF_SAVE_CODE: كود حماية حفظ القيادة.
- CIA_MEMBER_REQUEST_CODE: كود إرسال طلب قبول العضو.
- ALLOWED_ORIGINS: قائمة Origins مفصولة بفواصل، مثل https://example.com.
- DATA_DIR: مجلد خاص لتخزين cia-data.json، ويفضل أن يكون خارج مجلد الملفات العامة.

في بيئة الإنتاج، يتوقف الخادم إذا لم تكن أكواد التهيئة معرفة.

## أوامر التحقق

- npm run check: فحص صياغة الخادم.
- npm test: تشغيل فحص الصياغة نفسه ضمن CI.

## ملاحظات أمنية

- لا يتم إرسال التقارير والقضايا وبيانات الحالة الحساسة للزوار غير المصادق عليهم.
- عمليات تحديث البيانات المشتركة محصورة بالقيادة.
- كلمات مرور الحسابات الجديدة تستخدم scrypt مع salt عشوائي.
- ملف البيانات لا يجب أن يكون داخل مجلد الملفات العامة.
- غيّر أكواد البيئة فورًا إذا ظهرت في سجل أو مستودع أو لقطة شاشة.
