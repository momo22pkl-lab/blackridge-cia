# BLACKRIDGE CITY CIA — Personnel Actions Module

وحدة تجريبية مستقلة لإجراءات الأفراد: التحذيرات، التقارير الرسمية بصيغة PDF، الإيقاف المؤقت، الفصل، وطلبات الاستفسار.

## تشغيل النسخة للتجربة على Replit

1. ارفع ملف ZIP إلى Replit أو فك ضغطه داخل مشروع تجريبي جديد.
2. تأكد أن إصدار Node.js هو 18 أو أحدث.
3. افتح Shell ونفّذ:
   ```bash
   npm install
   npm start
   ```
4. افتح Webview. يمكنك تغيير رتبة المعاينة من أعلى الصفحة، وتغيير كود الحساب التجريبي من القائمة المجاورة.
5. لتجربة التقرير: اختر `HIGH COMMANDER` أو `SENIOR COMMANDER`، أصدر تحذيرًا، ثم اختر كتابة تقرير، واكتب تفاصيل الواقعة، واضغط **توليد PDF وإرساله للقيادة**. بعد ذلك افتح **التحذيرات والتقارير** بصلاحية `CIA CHIEF` أو `SENIOR COMMANDER` لتنزيل التقرير.
6. لتجربة الإيقاف: اختر القائد أو السينيور، ثم **إيقاف مؤقت**. اختر «دقيقة واحدة (اختبار)». افتح بوابة الفرد بالكود المستهدف لتظهر رسالة الإيقاف. ينتهي الإيقاف تلقائيًا بعد انتهاء المدة، ويمكن للقائد رفعه قبل ذلك. السينيور يستطيع رفع الإيقاف الذي أصدره بنفسه فقط.
7. لتجربة الفصل: اختر `CIA CHIEF`، ثم افتح قائمة الأفراد أو لوحة القيادة واضغط **فصل**. أدخل سبب الفصل. عند معاينة ذلك الحساب بصلاحية `AGENT` ستظهر رسالة **أنت مفصول** مع نموذج الاستفسار.

## الصلاحيات المطبقة في النموذج

- **CIA CHIEF:** تظهر له الهويات الحقيقية، ويستطيع إصدار التحذيرات، الإيقاف ورفعه، الفصل من لوحة القيادة أو قائمة الأفراد، والاطلاع على التقارير والاستفسارات.
- **SENIOR COMMANDER:** يستطيع إصدار التحذيرات والإيقاف المؤقت ورفع الإيقاف الذي أصدره بنفسه. يرى التقارير الرسمية دون الهويات الحقيقية، ولا يستطيع الفصل.
- **HIGH COMMANDER:** يستطيع إصدار التحذيرات. بعد التحذير تظهر له خطوة اختيارية لكتابة تقرير وتحويله إلى PDF وإرساله إلى السجل القيادي. لا يستطيع الإيقاف أو الفصل ولا يستطيع الاطلاع على خانة التقارير.
- **AGENT:** تعرض الواجهة الكود العسكري وحالة التحذير فقط. لا تعرض الاسم الحقيقي أو هوية مصدر العقوبة. يظهر له تنبيه الحساب عند الإيقاف أو الفصل، ويمكنه إرسال استفسار.

## الملفات

- `server.js`: خادم Express ونقاط API والتحقق من الصلاحيات في النموذج.
- `public/index.html`: الواجهة الرئيسية.
- `public/style.css`: التصميم المتجاوب.
- `public/app.js`: التفاعل والنماذج وتوليد PDF في المتصفح.
- `data/state.json`: تنشأ تلقائيًا لحفظ بيانات التجربة.
- `data/reports/`: تحفظ فيها ملفات PDF، ولا تُقدّم كمجلد عام.
- `REPLIT_MERGE_PROMPT_AR.txt`: تعليمات جاهزة لإعطائها إلى Replit لدمج الوحدة داخل المشروع الأصلي بشكل تزايدي.

## ملاحظات مهمة قبل الدمج في موقع BLACK RIDGE CIA الأصلي

**هذا المشروع حزمة تجربة مرجعية، وليس تعديلًا على ملفات موقعك الأصلي.** ملفات موقعك الأصلي لم تكن مرفقة بهذه المحادثة؛ لذلك لم أستبدلها أو أدّعِ أنني ربطت الوحدة بها.

- محدد الرتبة في أعلى الصفحة ومعرّف `X-Demo-Role` مخصصان للمعاينة فقط ويمكن تقليدهما من المتصفح. قبل الإنتاج يجب استعمال الجلسة/التوثيق الحالي في مشروعك، والحصول على رتبة المستخدم من الخادم لا من طلب المتصفح.
- بيانات JSON ومجلد PDF هنا للتجربة المستقلة. في نشر Render، اربط الوظائف بقاعدة PostgreSQL الحالية (`DATABASE_URL`) وتخزين ملفات دائم أو عمود `BYTEA`، ولا تعتمد على نظام الملفات المؤقت لحفظ بيانات الإنتاج.
- يجب أن يتحقق الخادم من صلاحية المستخدم عند كل عملية، وألا يعتمد على إخفاء عناصر الواجهة فقط.
- ملفات PDF لا تتضمن الأسماء الحقيقية؛ لأن خانة التقارير مرئية للقائد والسينيور، والهوية الحقيقية مقصورة على القائد.
- إذا لم تعمل مكتبة توليد PDF بسبب منع CDN، تحقق من اتصال المتصفح بالإنترنت. يمكن لفريق الدمج تضمين المكتبة محليًا داخل المشروع.
